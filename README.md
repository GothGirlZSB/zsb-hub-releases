# ZSB Hub — downloads

ZSB Hub clicks for your case-clicker accounts around the clock (money or cases) and collects their vaults. This page only holds the installers; the app updates itself after the first install.

## Install (Windows)

1. Download **ZSB-Hub-Setup-x.y.z.exe** from the [latest release](../../releases/latest).
2. Run it. Windows will say *"Windows protected your PC"* — click **More info**, then **Run anyway**. It only asks once: updates install by themselves after that.
3. Pick where to install it and how it starts, then click **Add account** in the app and sign in on the real case-clicker page. The app keeps the session, never your password.

## Updates

The app checks for new versions by itself. When one is ready, the top bar shows **Update ready — Restart to update**. Your accounts and settings are kept.

## Something wrong?

Click **Copy report** in the app and send the text to whoever gave you ZSB Hub. It has no account names, tokens or addresses in it.
